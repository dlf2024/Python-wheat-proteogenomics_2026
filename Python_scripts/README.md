# Python Scripts

This folder contains standalone Python scripts corresponding to the major analytical and computational steps of the wheat proteogenomics workflow.

The scripts were derived from the primary JupyterLab workflow notebook and are provided to improve:
- reproducibility,
- modular reuse,
- workflow transparency,
- code inspection outside JupyterLab.

The notebook version remains the authoritative and fully documented workflow because it contains:
- detailed markdown annotations,
- methodological explanations,
- intermediate outputs,
- visualisations,
- execution order context.

Primary notebook:

```text
notebooks/Vincent_Proteogenomics_wheat_2026-05-18_dlf2024.ipynb
```

---

# Script Overview

| Script | Purpose |
|---|---|
| `01_gff3_parsing.py` | Parse HC and LC wheat GFF3 annotation files and extract genomic features |
| `02_fragpipe_annotation.py` | Process FragPipe peptide/protein identification outputs |
| `03_peptide_protein_evidence.py` | Summarise peptide and protein evidence across datasets |
| `04_protein_gene_mapping.py` | Build protein-to-gene mapping tables from wheat annotations |
| `05_peptide_genome_projection.py` | Project peptide coordinates onto genomic intervals using GFF3 exon structures |
| `06_projection_validation.py` | Validate peptide coordinate reconstruction and exon-aware mappings |
| `07_sanity_checks.py` | Perform workflow integrity checks and diagnostic summaries |
| `08_BED_file_generation.py` | Generate BED6 and BED12 genome browser tracks |
| `09_non-redundant_BED_file.py` | Create non-redundant combined peptide projection tracks |
| `10_EDA-by-chromosome_violin-plot.py` | Exploratory analysis of chromosome-level peptide distributions |
| `11_EDA-by-chromosome_circular-plot.py` | Generate chromosome-scale circular proteogenomic visualisations |
| `12_EDA-by-confidence_boxplot-histogram.py` | Visualise HC vs LC peptide evidence distributions |
| `13_EDA-by-tissue_barplot.py` | Tissue-level proteogenomic coverage summaries |
| `14_EDA-by-tissue_UpSet-plot.py` | Tissue overlap analysis using UpSet plots |
| `15_EDA-by-confidence_scatterplot-length-vs-count.py` | Explore peptide length and evidence relationships |

# Workflow Context

These scripts collectively support the complete proteogenomics workflow described in the associated manuscript:

> *A Scalable Proteogenomic Genome-Mapping Workflow for Public Wheat Proteomics Datasets*

The workflow integrates:
- public LC-MS/MS proteomics datasets,
- FragPipe/MSFragger peptide identification,
- IWGSC RefSeq v2.1 wheat genome annotations,
- exon-aware peptide genome projection,
- BED6/BED12 track generation,
- Apollo JBrowse deployment,
- exploratory data analysis (EDA).

---

# Notes

## Input dependencies

Many scripts require:
- FragPipe result tables,
- wheat HC/LC GFF3 annotation files,
- peptide FASTA files,
- intermediate tables generated by earlier workflow steps.

Scripts are therefore intended to be executed sequentially or within the accompanying notebook workflow.

---

## Genome browser outputs

Generated BED6 and BED12 files are compatible with:
- Apollo,
- JBrowse,
- IGV,
- UCSC Genome Browser-compatible viewers.
